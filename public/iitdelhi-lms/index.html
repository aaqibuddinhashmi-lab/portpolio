02

About Project

Designed for CSC e-Governance Services India Limited at IIT Delhi, this Learning Management System (LMS) is a unified digital platform built to streamline academic operations through three dedicated interfaces — Student, Faculty, and Admin.

Each module is tailored to its users while remaining seamlessly connected within one centralized ecosystem. The project focused on scalable workflows, intuitive user experiences, course management, assessments, and system-wide consistency through a robust design system.

03
